# GUILibExt

GUILib extension for Turbowarp.

## ⚠️ WARNING

**Extension translation is NOT finished. Some blocks are in French.**

## Overview

`GUILibExt` is a small extension project for Turbowarp that adds GUI-oriented functionality to projects built around the GUILib ecosystem. The goal is to provide a reusable, extensible base for creating richer interactive interfaces and custom UI behaviors in Turbowarp-compatible environments.

## Features

- GUI-focused extension logic for Turbowarp
- Extensible structure for future widgets and helpers
- Open-source project with an MIT license
- Designed for experimentation and custom UI development

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/xNrep/GUILibExt.git
   ```
2. Open the project in your Turbowarp extension development workflow.
3. Build or package the extension according to your preferred setup.
4. Load the resulting extension into Turbowarp and begin using the GUI features.
