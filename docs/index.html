Build GUIs inside TurboWarp

GUILib is a JavaScript extension for creating panels, windows, labels, buttons, inputs and other interface elements directly in a TurboWarp project.

Installation

  1. Open TurboWarp and open the Extensions menu.
  2. Choose the option to load an extension from a URL or local file.
  3. Use the repository's GUILib.js file.
  4. Enable the extension and start building your interface.
GUILib uses browser DOM APIs, so it is intended for TurboWarp-style unsandboxed extensions.

Basic workflow

The usual workflow is simple: show the GUI, create elements, configure them, then react to user interaction.

Properties and management

Use the element ID to modify or inspect an existing element.

OperationPurpose
Set propertyChange position, size, text, value or styling-related properties.
Get propertyRead an element value or property.
ExistsCheck whether an element ID is registered.
RemoveDelete one element.
Bring to frontRaise an element above other GUI elements.
Set draggableEnable or disable dragging for supported elements.

Events

GUILib exposes event blocks for interaction such as button clicks and value changes. Give interactive elements stable IDs so your project logic can identify them.

  • When element clicked — react to a click.
  • When element changed — react to input, checkbox, slider or dropdown changes.
  • When modal confirmed — react to modal confirmation.
  • When tab changed — react to tab selection changes.

Visual editor

Use Open Editor to open the GUILib editor in a new browser tab. The editor provides a canvas, hierarchy, selection, dragging, resizing, grid/snap controls, duplication and deletion.

The editor can export the current layout as JSON and import it again later, making it useful for designing interfaces before wiring them to project logic.

JSON layouts

Exported layouts are designed to make interface positions portable. Keep your exported JSON with your project source if you want a reproducible UI layout.

{
  "version": 1,
  "elements": [
    {
      "id": "title",
      "type": "label",
      "text": "Hello"
    }
  ]
}

Troubleshooting

  • Nothing appears: make sure Show GUI has been run and the project is using TurboWarp-compatible unsandboxed extension support.
  • An element is missing: verify its ID is unique and that the creation block ran before property blocks.
  • The editor does not open: check whether the browser blocked a new tab or popup.
  • Changes are not visible: clear the GUI and recreate the element, or use the editor refresh controls.
